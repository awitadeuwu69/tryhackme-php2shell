# Evidencias del laboratorio

## Capturas

Las capturas originales compartidas durante la práctica muestran:

- Identificación del contenedor `php2shell-target` y la imagen PHP 8.4.26 Apache.
- Publicación local del servicio en `127.0.0.1:8088`.
- Comprobación HTTP del endpoint.
- Ejecución del exploit y etapas de fuga de memoria.
- Prueba de ejecución de comandos como `www-data`.
- Pantalla de TryHackMe con la sala completada.

## Tratamiento de información sensible

La flag aparece en la captura de finalización, por lo que no se debe subir esa imagen sin ocultar previamente su valor. Este repositorio documenta que la flag fue validada, pero no almacena su contenido.

Tampoco deben incluirse credenciales SSH, tokens, cookies de sesión ni claves privadas.
