# Referencias y fuentes

## Fuentes primarias

1. [TryHackMe - PHP2Shell](https://tryhackme.com/room/cvephp2shell) - objetivos y práctica guiada.
2. [PHP - Security advisories and releases](https://www.php.net/) - aviso oficial y versiones corregidas.
3. [Calif Research - PHP2Shell: A tale of two PHP remote vulnerabilities](https://calif.io/php2shell/) - explicación técnica e historia de investigación.

## Fuentes de análisis y respuesta

4. [CERT-EU Security Advisory 2026-018](https://cert.europa.eu/publications/security-advisories/2026-018/) - impacto y recomendaciones.
5. [Elastic Security Labs - PHP2Shell detection coverage](https://www.elastic.co/security-labs/threat-command/php2shell-php-rce-detection) - telemetría y detección.
6. [CISA - Critical Vulnerabilities in PHP](https://www.cisa.gov/news-events/alerts) - recomendaciones para defensores.
7. [Ciberseguridad UdeC - PHP vulnerabilidades críticas](https://ciberseguridad.udec.cl/php-vulnerabilidades-criticas-vulnerabilidad-critica/) - resumen local en español.

## Criterios de uso

- Priorizar el aviso oficial de PHP para versiones afectadas y correcciones.
- Usar fuentes de terceros para ampliar contexto y detección, no para sustituir la fuente primaria.
- Registrar fecha de consulta cuando se agreguen nuevos datos.
- Distinguir los hechos confirmados de hipótesis y observaciones del laboratorio.
